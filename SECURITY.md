# Politique de sécurité

## Versions supportées

Le projet est en version initiale `0.1.x`. Les correctifs de sécurité doivent viser la branche principale tant qu'aucune branche de maintenance n'existe.

## Signaler une vulnérabilité

Ne publie pas de vulnérabilité exploitable dans une issue publique.

Utilise les canaux privés disponibles sur le dépôt GitHub, par exemple une alerte de sécurité privée si elle est activée. Si aucun canal privé n'est configuré, contacte directement le mainteneur du dépôt.

Inclure si possible:

- La version concernée.
- Le système d'exploitation.
- Les étapes minimales de reproduction.
- L'impact attendu.
- Une proposition de correctif, si disponible.

## Données sensibles

Cette application peut manipuler des URLs, chemins locaux et fichiers média. Ne partage pas publiquement de logs contenant des liens privés, chemins personnels, cookies, jetons ou fichiers téléchargés.
